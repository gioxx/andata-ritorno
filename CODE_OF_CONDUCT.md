# Code of Conduct

A/R (Andata e Ritorno) adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

The full text is maintained upstream at the link above. By participating in this project (issues, discussions, pull requests or any other channel) you agree to abide by it.

## Scope

This Code of Conduct applies within all project spaces (repository, issues, pull requests, discussions, release artifacts) and when an individual is officially representing the project in public spaces.

## Reporting

Reports of unacceptable behavior may be sent privately to the maintainer at [hello@ar.gxware.org](mailto:hello@ar.gxware.org).

All reports are reviewed promptly and fairly, and the privacy and safety of the reporter are respected.

## Enforcement

The maintainer is responsible for clarifying and enforcing this Code of Conduct and may take any action deemed appropriate, up to and including a temporary or permanent ban from project spaces, as outlined in the Contributor Covenant's enforcement guidelines.
